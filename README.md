# README.md для проекта «Exploring Django»
## 1. О проекте
Проект «Exploring Django» — это демонстрационное веб-приложение, разработанное с использованием фреймворка Django. Цель проекта — изучить основные возможности Django, включая работу с моделями, представлениями, шаблонами и URL-маршрутизацией.
## 2. Структура проекта
Проект имеет следующую структуру:
- `catalog/` — приложение для работы с каталогом. Содержит:
- `migrations/` — файлы миграций для базы данных;
- `templates/` — HTML-шаблоны для отображения страниц (например, `contacts.html`, home.html);
- `__init__.py`, `admin.py`, `apps.py`, `models.py`, `tests.py`, `urls.py`, `views.py` — основные файлы приложения.
- `config/` — корневая директория проекта, содержит:
- `asgi.py` — конфигурация ASGI (Async Server Gateway Interface);
- `settings.py` — настройки проекта (конфигурация базы данных, статических файлов и т. д.);
- `urls.py` — маршрутизация URL для всего проекта;
- `wsgi.py` — конфигурация WSGI (Web Server Gateway Interface).
- `venv/` — виртуальное окружение проекта.  
### Прочие файлы:
- `.gitignore` — список игнорируемых файлов для Git;
- `db.sqlite3` — файл базы данных SQLite3;
- `manage.py` — утилита для управления проектом (запуск сервера, создание миграций и т. д.);
- `poetry.lock`, `pyproject.toml` — файлы конфигурации для Poetry (инструмент управления зависимостями).
## 3. Используемые технологии
- `Django` — веб-фреймворк для Python;
- `Python` — язык программирования;
- `SQLite3` — встроенная СУБД для хранения данных;
- `Poetry` — инструмент для управления зависимостями и виртуальными окружениями;
- `HTML/CSS` — для создания шаблонов.
## 4. Установка и запуск
### Шаг 1. Клонируйте репозиторий:
```
git clone <ссылка на репозиторий>
```
### Шаг 2. Активируйте виртуальное окружение:
```
source venv/bin/activate  # для Linux/MacOS
venv\Scripts\activate     # для Windows
```
### Шаг 3. Установите зависимости с помощью Poetry:
```
poetry install
```
### Шаг 4. Примените миграции:
```
python manage.py migrate
```
### Шаг 5. Запустите сервер разработки:
```
python manage.py runserver
```
После этого приложение будет доступно по адресу `http://127.0.0.1:8000`.
## 5. Функционал
- Отображение домашней страницы (`home.html`);
- Страница контактов (`contacts.html`);
- Работа с базой данных через модели Django (`models.py`);
- Управление URL-адресами через `urls.py`;
- Админ-панель для управления содержимым (доступ через `/admin/`).
